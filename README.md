# Крыши

3D-паркур по крышам города в стиле Roblox для Android.

- Свободный бег по крышам: двойной прыжок, сальто, подкат, отскок от стены, батуты, мостики, лифты.
- Бандиты на крышах, 9 видов оружия, оружейные магазины.
- Живой город: машины, на которых можно ездить, прохожие с заданиями.
- Свой дом с холодильником, кроватью, тренажёром улучшений и питомцами.
- Банки, супермаркеты с полками, 7 карт за порталами (открываются за деньги).

Игра — страница `app/src/main/assets/index.html` на three.js (лежит рядом, работает без интернета), показанная во весь экран через WebView. Прогресс хранится на телефоне.

Сборка: GitHub Actions на каждый push в `main`, APK — в Releases.
